1. What is DOM in JavaScript? Why do we need DOM?
DOM stands for Document Object Model.

The DOM is a representation of an HTML page as a tree of objects. JavaScript uses the DOM to access and change HTML elements.

We need the DOM because it allows JavaScript to make a webpage interactive and dynamic.

For example, JavaScript can:

Change text
Change CSS
Add or remove HTML elements
Respond to button clicks
Add or remove classes
Read user input
Example:

document.getElementById("heading").textContent = "Hello!";

This changes the text of an HTML element.

2. What is the difference between HTML and DOM?
HTML	DOM
HTML is the code written in an HTML file.	DOM is the browser's representation of that HTML.
It describes the structure of a webpage.	It represents the webpage as objects/nodes.
It is mainly used to create the page.	It is used by JavaScript to access and modify the page.
Example: <h1>Hello</h1>	JavaScript can access that <h1> as a DOM element.

Example
HTML:

<h1 id="heading">Hello</h1>

JavaScript uses the DOM:

const heading = document.getElementById("heading");
heading.textContent = "Hello World";

3. What is the document object in JavaScript?
The document object represents the HTML document loaded in the browser.

It is the main entry point for working with the DOM.

For example:

document.getElementById("heading");
document.querySelector(".para");
document.querySelectorAll("p");

Here, document is used to find HTML elements.

5. Difference between getElementById() and querySelector()
getElementById()
Selects an element using its ID.

const heading = document.getElementById("heading");

HTML:

<h1 id="heading">Hello</h1>

It returns one element.

querySelector()
Selects the first element that matches a CSS selector.

const heading = document.querySelector("#heading");

It can select by ID, class, tag, etc.

document.querySelector("#heading");
document.querySelector(".para");
document.querySelector("p");

Main difference
getElementById()	querySelector()
Only searches by ID	Can use CSS selectors
Returns the element with that ID	Returns the first matching element
getElementById("heading")	querySelector("#heading")

6. Difference between querySelector() and querySelectorAll()
querySelector()
Returns the first matching element.

const para = document.querySelector(".para");

If you have:

<p class="para">One</p>
<p class="para">Two</p>
<p class="para">Three</p>

Only "One" is selected.

querySelectorAll()
Returns all matching elements.

const para = document.querySelectorAll(".para");

It selects all three paragraphs.

To change all of them, we can use forEach():

const para = document.querySelectorAll(".para");

para.forEach(function (p) {
  p.textContent = "Changed!";
});

Main difference
querySelector()	querySelectorAll()
Selects first matching element	Selects all matching elements
Returns one element	Returns a collection of elements
No loop normally needed	forEach() can be used to process each element

7. Difference between textContent, innerText, and innerHTML
textContent
Gets or changes text content.

heading.textContent = "Hello World";

If you write:

heading.textContent = "<span>Hello</span>";

It displays the tags as text:

<span>Hello</span>

innerText
Gets or changes the visible text of an element.

heading.innerText = "Hello World";

It is more related to what is actually displayed on the page.

innerHTML
Gets or changes the HTML inside an element.

heading.innerHTML = "<span>Hello World</span>";

The <span> is treated as HTML and becomes an actual element.

Easy way to remember
textContent → Text
innerText   → Visible text
innerHTML   → HTML

8. How can we change the CSS style of an HTML element using JavaScript?
We can use the style property.

Example:

const heading = document.getElementById("heading");

heading.style.color = "red";
heading.style.backgroundColor = "yellow";
heading.style.fontSize = "40px";

HTML:

<h1 id="heading">Hello</h1>

We can also add a CSS class using classList.add():

heading.classList.add("newStyle");

CSS:

.newStyle {
  color: blue;
  font-size: 40px;
}
